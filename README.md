# Titanic — Прогноз выживаемости пассажиров

Учебный проект по бинарной классификации: предсказание, выжил ли пассажир "Титаника",
на основе демографических и билетных данных.

Соревнование на Kaggle: https://www.kaggle.com/competitions/titanic

## Задача

Бинарная классификация (0 = не выжил, 1 = выжил) на основе признаков:
пол, возраст, класс каюты, порт посадки, размер семьи на борту и др.

## Данные

Датасет от Kaggle: `train.csv` (891 пассажир, с ответами) и `test.csv` (418 пассажиров, без ответов).

## Подход

1. Разведочный анализ данных (EDA)
2. Обработка пропусков: Age и Fare — медианой по группам (Pclass, Sex), Embarked — модой; Cabin удалена из-за 77% пропусков
3. Feature engineering: титул из имени, размер семьи
4. Кодирование категориальных признаков
5. Baseline-модель: логистическая регрессия
6. Кросс-валидация

## Результат

| Модель | Локальный score (CV) | Kaggle Public Score |
|---|---|---|
| Logistic Regression (baseline) | 0.820 | 0.775 |

## Выводы

- Модель показала accuracy 0.775 на Kaggle — чуть выше базового правила "все женщины выживают, все мужчины гибнут" (0.766), что ожидаемо для простого baseline на логистической регрессии.
- Разрыв между CV-score (0.820) и Kaggle score (0.775) в пределах нормы и не указывает на переобучение.
- Анализ коэффициентов модели показал, что сильнее всего на выживание влияли титул `Mr` (сильно отрицательно) и класс каюты `Pclass` — это соответствует историческому правилу "женщины и дети — вперёд" и приоритету пассажиров высокого класса при посадке в шлюпки.
- Признаки `Age` и `Fare` показали слабое влияние в текущем виде — вероятно, потребуют масштабирования (StandardScaler) для более честной оценки их важности.
