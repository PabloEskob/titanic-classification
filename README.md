# Titanic — Прогноз выживаемости пассажиров

Учебный проект по бинарной классификации: предсказание, выжил ли пассажир "Титаника",
на основе демографических и билетных данных.

Соревнование на Kaggle: https://www.kaggle.com/competitions/titanic

## Задача

Бинарная классификация (0 = не выжил, 1 = выжил) на основе признаков:
пол, возраст, класс каюты, порт посадки, размер семьи на борту и др.

## Данные

Датасет от Kaggle: `train.csv` (891 пассажир, с ответами) и `test.csv` (418 пассажиров, без ответов).

## Подход

1. Разведочный анализ данных (EDA)
2. Обработка пропусков (Age, Embarked, Cabin)
3. Feature engineering: титул из имени, размер семьи, признак "один ли пассажир"
4. Кодирование категориальных признаков
5. Baseline-модель: логистическая регрессия
6. Кросс-валидация и сравнение с другими моделями
